## Quick Start

- 複製版本庫

```shell
git clone network_delay_dashboard
cd network_delay_dashboard
```

- 透過docker啟動採集器與顯示圖表的網頁

```shell
docker compose up -d
```

- 匯入dashboard `./dashboard/Network Delay.json/`
